## 📌 About This Repository

This is my **personal Python learning journal** — a repository where I track practice sessions, exercises, and assignments as I build skills from Python fundamentals through to data science and machine learning, under the guidance of Yameen Hakim.

> **Goal:** Build a strong foundation in Python, then progress through data science (NumPy, pandas, matplotlib/seaborn), data preprocessing, and machine learning (regression, clustering, classification) through consistent, hands-on practice.

---

## 🎯 Learning Objectives

- ✅ Understand core Python syntax, data types, and control flow
- ✅ Master Python's built-in data structures (lists, tuples, sets, dicts)
- ✅ Write and use functions confidently
- ✅ Work through conditional logic and iteration problems
- ✅ Apply concepts through graded assignments
- ✅ Work with NumPy arrays and pandas DataFrames
- ✅ Visualize data with matplotlib and seaborn
- ✅ Handle outliers, imbalanced data, and preprocessing
- ✅ Build regression models (linear, multilinear, logistic)
- ✅ Build classification/clustering models (KNN, KMeans)
- 🔜 Explore more advanced ML algorithms

## 🚀 How to Run Notebooks

**Prerequisites:** Python 3.x and `pip` installed.

```bash
# 1. Clone this repository
git clone https://github.com/abdulmutallib990-netizen/python.git
cd python

# 2. Install dependencies
pip install jupyter numpy pandas matplotlib seaborn scikit-learn

# 3. Launch Jupyter
jupyter notebook
```

Then navigate into `python-basics/`, `data-science/`, `data-preprocessing/`, `machine-learning/`, `practice_problems/`, or `assignments/` and open any `.ipynb` file.
